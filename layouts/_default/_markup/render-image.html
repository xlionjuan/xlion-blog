{{- define "RenderImageSimple" -}} {{- $imgObj := .imgObj -}} {{- $src := .src -}} {{- $alt := .alt -}} {{- end -}} {{- define "RenderImageResponsive" -}} {{- $imgObj := .imgObj -}} {{- $alt := .alt -}} {{- $originalWidth := $imgObj.Width -}} {{- $widths := slice (math.Min 800 $originalWidth | int) (math.Min 1280 $originalWidth | int) | uniq -}} {{- $srcset := slice -}} {{- $srcsetAvif := slice -}} {{- $srcsetWebp := slice -}} {{- $fallback := $imgObj -}} {{- $sizes := "(min-width: 768px) 50vw, 65vw" -}} {{- range $index, $width := $widths -}} {{- $original := $imgObj -}} {{- if lt $width $originalWidth -}} {{- $original = $imgObj.Resize (printf "%dx" $width) -}} {{- end -}} {{- if eq $index 0 -}} {{- $fallback = $original -}} {{- end -}} {{- $avif := $imgObj.Resize (printf "%dx avif" $width) -}} {{- $webp := $imgObj.Resize (printf "%dx webp" $width) -}} {{- $srcset = $srcset | append (printf "%s %dw" $original.RelPermalink $original.Width) -}} {{- $srcsetAvif = $srcsetAvif | append (printf "%s %dw" $avif.RelPermalink $avif.Width) -}} {{- $srcsetWebp = $srcsetWebp | append (printf "%s %dw" $webp.RelPermalink $webp.Width) -}} {{- end -}} {{- end -}} {{- define "RenderImageCaption" -}} {{- with .caption -}} {{- end -}} {{- end -}} {{- $disableImageOptimizationMD := .Page.Site.Params.disableImageOptimizationMD | default false -}} {{- $urlStr := .Destination | safeURL -}} {{- $url := urls.Parse $urlStr -}} {{- $altText := .Text -}} {{- $caption := .Title -}} {{- $isRemote := findRE "^(https?|data)" $url.Scheme -}} {{- $resource := "" -}} {{- if not $isRemote -}} {{- $resource = or ($.Page.Resources.GetMatch $urlStr) (resources.Get $urlStr) -}} {{- end -}}
